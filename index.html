Problem

Dokumen vendor dibuat manual satu per satu — ±15 menit per dokumen, rawan human error — di tengah volume 1.871+ PO dan ratusan mitra yang harus diproses bersamaan. Tidak ada sistem, tidak ada template terpusat, tidak ada instruksi untuk membangunnya.

  • Data tersebar di beberapa spreadsheet berbeda
  • Tidak ada validasi duplikasi
  • Risiko ketidaksesuaian data tinggi di skala besar
  • Tidak ada auto-filing ke folder yang tepat
Solusi yang Dibangun

Sistem otomasi berbasis Google Apps Script yang mengintegrasikan beberapa sumber data, men-generate 10+ jenis dokumen secara otomatis, dan menyimpan ke folder Google Drive yang sesuai — lengkap dengan validasi dan error handling.

  • Lookup & data matching lintas spreadsheet via Sheets API
  • Auto-sync trigger berbasis event — data ter-update otomatis
  • Custom search UI dengan real-time filtering
  • Validasi anti-duplikasi dan retry logic untuk error handling
  • 10+ template dokumen dengan auto-folder di Drive
